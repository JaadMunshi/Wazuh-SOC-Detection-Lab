\# MITRE ATT\&CK Mapping

The custom Wazuh detection rules created in this project were mapped to the relevant MITRE ATT\&CK techniques.



\## Detection Mapping

| Rule ID | Detection | MITRE ATT\&CK Technique |

|---|---|---|

| 100050 | Port Scan | T1046 — Network Service Scanning |

| 100060 | Suspicious Process | T1059 — Command and Scripting Interpreter |

| 100070 | Brute Force | T1110 — Brute Force |

| 100080 | SMB Connection | T1021.002 — SMB/Windows Admin Shares |



\## Purpose

I used MITRE ATT\&CK mapping to show which attacker techniques each custom detection rule is designed to identify.

This gives the detections a standard classification and shows how they relate to a real-world attackers behaviour.
